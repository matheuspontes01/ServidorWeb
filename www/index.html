Servidor Web Simplificado

Projeto desenvolvido com sockets TCP e threads para atender vários clientes de forma simultânea.

01

Comunicação TCP

O cliente envia uma solicitação e recebe o conteúdo solicitado pelo servidor.

02

Múltiplos clientes

Cada conexão é atendida em uma thread independente no servidor.

03

Arquivos da pasta WWW

Os recursos disponíveis são localizados e enviados a partir da pasta pública.

Exemplo de requisição

GET /index.html
